# 🤖 Crypto Signal Bot

ربات تحلیل و سیگنال‌دهی رمزارز با قابلیت‌های پیشرفته تکنیکال، خبرخوان، و تحلیل هوش مصنوعی

## 🚀 ویژگی‌ها

- **تحلیل تکنیکال پیشرفته**: RSI، MACD، EMA، SMA، ADX، ATR، Bollinger Bands
- **تحلیل حجم معاملات**: تشخیص افزایش‌های غیرعادی حجم
- **مدیریت ریسک**: محاسبه حد ضرر و اهداف بر اساس ATR
- **سیستم امتیازدهی**: ترکیب ۷ عامل مختلف با وزن‌های قابل تنظیم
- **اخبار بازار**: دریافت خلاصه اخبار از Nitrimo Radar
- **تحلیل هوش مصنوعی**: نظر تکمیلی AI بر اساس داده‌های تکنیکال و اخبار
- **ارسال به بله**: ارسال خودکار سیگنال‌ها به پیام‌رسان بله
- **سیستم اطمینان**: ترکیب امتیاز فعلی و عملکرد تاریخی
- **مدیریت اسپم**: جلوگیری از ارسال پیام‌های تکراری

## 📋 پیش‌نیازها

- Python 3.9+
- pip
- توکن ربات بله
- (اختیاری) کلید API OpenAI
