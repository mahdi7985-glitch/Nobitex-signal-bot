🤖 Nobitex Signal Bot

ربات شخصی تحلیل و پایش بازار رمزارزها که با دریافت داده‌های بازار از نوبیتکس، از ترکیب شاخص‌های تکنیکال، تحلیل حجم، مدیریت ریسک و سیستم امتیازدهی برای بررسی شرایط بازار و تولید سیگنال‌های خرید و فروش استفاده می‌کند.

این پروژه به‌صورت شخصی و با کمک ابزارهای هوش مصنوعی در حال توسعه است و هدف آن یادگیری، آزمایش ایده‌های مختلف تحلیل بازار و بررسی عملکرد یک سیستم معاملاتی الگوریتمی با داده‌های واقعی است.

🚀 ویژگی‌ها

- 📊 تحلیل تکنیکال: RSI، MACD، EMA، SMA، ADX، ATR و Bollinger Bands
- 📈 تحلیل حجم معاملات: بررسی افزایش‌های غیرعادی حجم
- 🛡️ مدیریت ریسک: محاسبه حد ضرر و اهداف قیمتی بر اساس ATR
- 🎯 سیستم امتیازدهی: ترکیب عوامل مختلف برای ارزیابی قدرت سیگنال
- 📰 تحلیل اخبار: دریافت و بررسی اخبار مرتبط با بازار
- 🤖 تحلیل هوش مصنوعی: استفاده از AI به‌عنوان یک فیلتر و نظر تکمیلی در کنار تحلیل اصلی
- 📱 ارسال اعلان: ارسال خودکار سیگنال‌ها به پیام‌رسان بله
- 📋 Paper Trading: شبیه‌سازی معاملات با داده‌های واقعی برای بررسی عملکرد سیستم بدون استفاده از سرمایه واقعی
- 🔄 پایش چندین ارز: بررسی هم‌زمان ۲۶ ارز دیجیتال
- 📊 ارزیابی عملکرد: بررسی نتایج معاملات شبیه‌سازی‌شده و شناسایی نقاط قوت و ضعف سیستم
